## Conventions
- **Conventional Commits** (`feat:`, `fix:`, `test:`, `docs:`, `refactor:`).
- **Atomic commits** — one logical change per commit (roughly one task/sub-task).
- **No AI/assistant references** in commit messages (no "generated by" notes or
  co-author trailers).
- **Short** commit subjects (imperative, ≤ ~50 chars).
- Every task ships with **unit tests**; the feature is also covered end-to-end (T019).

## Phase 1 — Matcher core (composite pattern)
- [ ] **T003** `pkg/filter/matcher.go`: `Matcher` interface (`Match` returns
      `bool` + `Key`) and `Composite` (skip if any matcher skips, is-a `Matcher`).
      No `Reason` type — skipped files are not tracked.
- [ ] **T004** Leaf matchers in `matcher.go`: `extMatcher`, `nameMatcher`,
      `dirMatcher` (name + suffix), `sizeMatcher` (min/max, optional pattern scope).
      Each carries its `Key`. (depends on T003)
- [ ] **T005** `globMatcher` wrapping the gitignore lib (negation/anchoring),
      with `Key()` = `glob:<pattern>`. (depends on T001, T003)
- [ ] **T006** `pkg/filter/build.go`: `Build(sources ...[]Matcher) *Composite` —
      concat, dedupe by `Key()` (collapse duplicates to one), wrap in `Composite`.
      (depends on T003)
- [ ] **T007** Tests `pkg/filter/matcher_test.go`: each leaf matcher; `Build`
      dedupe collapses same `Key()` to a single matcher. (depends on T004–T006)

## Phase 2 — Sources & Collect
- [ ] **T008** `pkg/filter/sources.go`: `DefaultSource(DefaultOptions) []Matcher`
      from the exported lists (respects override/extend). (depends on T002, T004)
- [ ] **T009** `SettingsSource(skip Skip, folders Folders) []Matcher` over local
      mirror structs: `skip.patterns` → glob matchers, `skip.sizes` → size matchers,
      `folders.include/exclude` → folder gate; operation-type aware. (depends on T004, T005)
- [ ] **T010** `GitIgnoreSource(root) ([]Matcher, error)`: parse `.gitignore`
      file(s) in the tree into glob matchers. (depends on T005)
- [ ] **T011** `pkg/filter/collect.go`: `Options`, `CollectResult{Files,
      SkippedCount}`, and `Collect(root, Options)` — build composite from enabled
      sources, one `filepath.WalkDir` (dir match → `fs.SkipDir`; file match →
      drop + `SkippedCount++`; else append to `Files`), absolute paths, no
      symlink-dir following. No per-file skipped list. (depends on T006, T008–T010)
- [ ] **T012** Tests `pkg/filter/collect_test.go`: fixture tree (`node_modules/`,
      `__pycache__/`, `vendor/`, `a.png`, `b.md`, 50-byte file, normal `.go`) →
      assert `Files` is exactly the expected kept set and `SkippedCount` matches;
      size rules; `folders.include/exclude`; `.gitignore`. (depends on T011)
