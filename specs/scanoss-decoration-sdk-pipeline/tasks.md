## Conventions

- **Atomic commits** — one logical change per commit (roughly one task/sub-task).
- **No AI/assistant references** in commit messages (no "generated by" notes or

## Phase 2 — DecorationPipeline core
- [ ] **T007** Add `pkg/scanoss/decoration_pipeline.go`: `DecorationPipeline` struct + `(*Client).DecorationPipeline`.
- [ ] **T008** Add `Add`/`Remove` (chainable, dedupe by `Service.name`) and
      `Services()`. (depends on T007)
- [ ] **T009** Implement `Run(ctx, []Component) (*PipelineResult, error)` —
      one goroutine per service via `client.Query`, collected with
      `sync.WaitGroup` + channel. (depends on T007)

## Phase 3 — Output & progress snapshot
- [ ] **T010** Add `PipelineResult{Services, Errors}` with `MarshalJSON`
      (keyed, full merged object via `Result.Merged()`) and `String()`. (depends on T009)
- [ ] **T011** `Run` error semantics: error only if every service failed;
      otherwise populate `Errors`. (depends on T009, T010)
- [ ] **T012** Add `PipelineProgress{Services map[string]Progress}` and
      `DecorationPipeline.OnProgress(func(PipelineProgress))`: the pipeline keeps a
      thread-safe per-service map, updates it from each service's `Progress`
      events, and delivers a snapshot copy to the consumer **serially**
      (no consumer-side locking). Add optional `Snapshot() PipelineProgress`
      pull accessor. (depends on T007, T009)
